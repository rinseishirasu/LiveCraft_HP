# Live Craft 公式サイト Ver.3.1 — Soft Atelier

**コンセプト：ふんわり、やさしく、でも洗練されたLive Craft。**

Ver.2.1の全10ページ（＋404）、LCロゴ、期生別メンバーアイコン一覧→詳細ポップアップ、NEWS、FAQ検索、問い合わせ導線はそのまま引き継ぎ、サイト全体をアイボリー・ラベンダー・淡いブルーで再設計しました。ロゴ画像は元のまま使用し、周囲のデザインを柔らかくしています。


## Ver.3.1 の追加機能：期生別メンバー紹介

- `MEMBERS` は公開済みメンバーを **1期生、2期生、3期生…** の番号順でグループ分けします。
- 一覧上部に **「すべて」「1期生」「2期生」…** の期生切り替えボタンを自動生成します。人数は現在のジャンル絞り込みに連動します。
- 従来の**ジャンル絞り込み**も利用可能です。期生・ジャンル両方の条件が適用されます。
- アイコンをクリックすると開く詳細画面に **「所属期生：1期生」** などを表示します。
- 期生を新設してもHTMLの編集は不要で、`assets/members.js` に `generation: 3` などを追加するだけで反映されます。
- 初期状態はメンバー0人、準備中表示です。公開に同意したデータのみ登録してください。
- 既に公開していたプロフィールに `generation` がない場合は自動的に **「期生未設定」** に表示し、勝手に1期生とすることはありません。

### メンバー登録例

```js
window.LIVE_CRAFT_MEMBERS = [
  {
    published: true,
    name: "活動名を記入",
    generation: 1,  // 1期生 = 1、2期生 = 2
    generation: 1, // 期生番号
    role: "メンバー",
    genres: ["ゲーム", "雑談"],
    bio: "配信活動についての自己紹介です。",
    avatar: "assets/members/profile-01.webp",
    links: [
      {label: "YouTube", url: "https://www.youtube.com/@your-channel"}
    ]
  }
];
```

上記は入力方法の例で、実在の所属メンバーを示していません。**既存の公開メンバー情報を更新するときは `generation: 1` のような項目をそれぞれのプロフィールに追加してください。**

### Ver.3.0から更新する場合

- HTMLは `members.html` のみ更新、JavaScriptは `assets/members-page.js` を更新、CSSは `assets/v3.css` を更新してください。
- 新規に配布した `assets/members.js` は空のテンプレートです。**公開済みのメンバー情報がある場合、このファイルを上書きせず、既存の各プロフィールに `generation` を追記してください。**
- それ以外のHTMLやNEWS、FAQ、設定ファイル等はVer.3.0と同じです。

## 公開前に必ず変更する設定

`assets/config.js` を編集してください。

```js
window.LIVE_CRAFT_CONFIG = {
  recruitmentOpen: false,
  applicationUrl: "",          // 公開済みGoogleフォームの回答者用リンク
  contactUrl: "",              // 公開可能な問い合わせフォーム等のURL
  rulesEffectiveDate: "未定",   // 例: 2026年11月1日
  rulesVersion: "1.0"
};
```

- `recruitmentOpen` と `applicationUrl` の**両方**が設定されたときだけ、応募ボタンを表示します。
- `contactUrl` が未設定の場合、CONTACTとPRIVACYには「準備中」と表示します。
- CONTACTの送信先は別サービス（Googleフォーム等）の**公開用URL**を設定します。個人情報をGitHubに保存しないでください。
- 規約本文は公開向けに要約・整形した版です。既存の正式な規約原稿と照合してから公開してください。
- `privacy.html` の内容は運営体制に合わせて最終確認してください。公開前に問い合わせ窓口も用意してください。
- 本リポジトリに応募情報、審査シート、メンバーの個人情報を置かないでください。

## Ver.3.0で追加した3ページ

### NEWS (`news.html`)

- 日付順の「お知らせ」一覧。記事タイトルをクリック／タップすると詳細を開けます。
- 分類が複数ある場合は「募集」「活動」「メンバー」「お知らせ」等のカテゴリー別に絞り込めます。
- `index.html` の「Live Craftの、今。」に最新3件を自動表示します。
- **初期状態は記事0件**です。存在しない活動実績・イベント日時を公開しないため、準備中表示を出しています。

記事追加は `assets/news.js` の `window.LIVE_CRAFT_NEWS` 配列を編集します（ファイル内にもコメント例があります）。

```js
window.LIVE_CRAFT_NEWS = [
  {
    published: true,
    date: "2026-11-01", // 必ず実際の公開日に変更
    category: "お知らせ",
    title: "【ここに正式な記事タイトル】",
    summary: "一覧・概要に使う短い文章。",
    body: ["詳細の1段落目。", "詳細の2段落目。"],
    link: "https://example.com" // 任意。不要なら行ごと削除
  }
];
```

`published: true` の記事だけが掲載されます。本文はHTMLではなく普通の文章で記入してください。記事内容は一般公開されます。

### FAQ (`faq.html`)

- 参加条件、審査・面談、活動ノルマ、兼任、未成年、情報公開などについて16問掲載しました。
- 検索ボックスから質問・回答の文字を検索できます。該当する質問だけが表示されます。
- FAQの質問や回答を編集する際は `faq.html` 内の `<details class="faq-item">` を編集します。
- JOIN USの「よくある質問」から詳細FAQページへ移動できます。

### CONTACT (`contact.html`)

- 加入に関する質問、コラボ依頼、規約・プライバシー関連の相談などの窓口を案内します。
- `assets/config.js` の `contactUrl` に**公開用の外部問い合わせフォーム**のURLを設定すると、リンクが表示されます。
- 未設定時は「準備中」表示で、フォームがあるように装うことはありません。
- GitHub Pagesは静的サイトのため、HTMLのみで問い合わせをサーバーへ送信する機能は備えていません。専用の外部フォームをご利用ください。

### ナビゲーション

- ヘッダー：HOME / ABOUT / ACTIVITIES / MEMBERS / NEWS / JOIN US
- フッター：FAQ / CONTACT / GUIDELINES / PRIVACY
- ブランド紹介→活動紹介→メンバー→お知らせ→応募という流れを継続します。

## GitHub Pagesへの公開手順

1. GitHubで新しい公開リポジトリ（例: `live-craft`）を作成します。
2. ZIPを解凍したフォルダー **内のファイルとフォルダー全部**をリポジトリのルートにアップロードします。
3. リポジトリの `Settings` → `Pages` へ移動します。
4. `Build and deployment` → `Source` を **Deploy from a branch** にします。
5. Branch を `main`、フォルダーを `/(root)` にして保存します。
6. 公開後に表示されるURL（通常 `https://ユーザー名.github.io/live-craft/`）で各ページを確認します。

パスはすべて相対指定なので、GitHub Pagesのプロジェクトサイトでも表示できます。ビルドツール・Node.js・サーバー側プログラムは不要です。


## メンバー紹介ページの公開方法（MEMBERS｜Ver.2.0）

メンバーのプロフィールは `members.html` に表示されます。**初期状態では0名、準備中表示**です。
一覧には**アイコン画像のみ**を並べ、クリック／タップでプロフィールがポップアップ表示されます。詳細には活動名、役割、ジャンル、自己紹介、各配信サイト・SNSへのリンクが載ります。Escキー・背景のクリック・右上の×ボタンで閉じられます。
実在のメンバー名や画像などを勝手に公開しないよう、必ず本人の同意を確認してください。

1. 活動名、紹介文、ジャンル、役割、掲載するSNSリンク、アイコン画像を本人に確認します。
2. 画像を使う場合は本人の許可を得て `assets/members/` に配置します。ファイル名は英数字、ハイフン、アンダースコアのみ推奨です。
3. `assets/members.js` のコメント内の記入例を参考に、`window.LIVE_CRAFT_MEMBERS` 配列にプロフィールを追加します。
4. **公開を承認済みのプロフィールだけ `published: true` にします。** 非公開の場合は配列に入れない方が安全です。アイコン画像・詳細の文章・外部リンクのそれぞれについて同意を確認してください。
5. 公開ページで表示、リンク、モバイルレイアウトを確認します。

設定例（**架空のサンプル**。公開ファイルには初期登録されていません）：

```js
window.LIVE_CRAFT_MEMBERS = [
  {
    published: true,
    name: "サンプル配信者",
    generation: 1, // 期生番号
    role: "メンバー",
    genres: ["ゲーム", "雑談"],
    bio: "自分らしい配信を磨いています。",
    avatar: "assets/members/sample.webp",
    links: [
      { label: "YouTube", url: "https://www.youtube.com/@example" },
      { label: "X", url: "https://x.com/example" }
    ]
  }
];
```

`avatar` は省略できます。その場合は活動名の頭文字が表示されます（できれば本人が許諾したアイコン画像を登録してください）。アイコンは1:1の正方形・推奨512×512pxのWebPまたはPNGです。SNSリンクには `https://` 形式を使ってください。
一覧はPCで最大6列、スマートフォンでは3列です。活動名を一覧に表示せず、スクリーンリーダーには「○○のプロフィールを見る」と読み上げられます。
複数ジャンルのメンバーが登録されると、ジャンル絞り込みが表示されます。

**重要：`members.js` や画像は公開リポジトリに含まれるため、`published: false` としても情報が非公開になるわけではありません。** 非掲載者のデータはファイルに保存しないでください。公開後の削除でもGitの履歴に残る場合があります。非公開情報は絶対にコミットしないでください。

## Ver.2.0 で追加した演出

- **Cinematic Hero**：従来のLCシンボルを中心に、回転する軌道、光、グリッド、浮遊感のあるロゴを配置。
- **Scroll reveal**：文章・カード・ステップがスクロールで現れます（IntersectionObserver）。
- **Card hover**：カード上のカーソル位置に沿った柔らかい光、シャープな浮上演出。
- **Page transitions**：対応ブラウザーのみ、同一サイト内のページ切り替えをフェード演出。非対応環境でも普通に遷移します。
- **Motion-safe**：OSの「視差効果を減らす / 動きを減らす」設定に従い、強いアニメーションを停止します。
- **Responsive**：PC・スマートフォンで異なるレイアウトを適用。メンバーモーダルは従来のクリック・Esc・背景クリックを維持。
- **No dependencies**：GSAP等の外部CDNを必要とせず、HTML/CSS/JSのみで動作します。公開は従来どおり簡単です。

**公開前の注意:** 募集フォームURL、問い合わせ先、規約の施行日と正式版の本文、プライバシー方針は未確定です。必ず運営側で確定してください。プロフィールには実在者の情報を初期登録していません。実際の画像を登録する際は本人の公開同意を取得してください。
