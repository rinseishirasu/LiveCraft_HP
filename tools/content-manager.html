LIVE CRAFT / CONTENT MANAGER

公開データの編集・検証・書き出しを行うローカル作業ツール。Webサイト上のデータは直接変更しません。

重要：この画面にはログイン機能も保存機能もありません。書き出したJavaScriptをGitHubにアップロードするとサイトが更新されます。公開許諾のない情報や応募者の個人情報を入力しないでください。機密データの管理には使用できません。

編集

各項目はJSON形式で編集できます。MEMBERSには任意の agency（所属事務所名・個人勢）も登録できます。配列・画像パス・公開日はREADMEをご覧ください。

公開判定の基本：published: true かつ必要項目が設定されている場合に表示。publishAt は画面上での時刻判定のみで、公開GitHubリポジトリのソースからは読めます。未発表情報の安全な予約公開には利用しないでください。
